# Night Camp wiki

ข้อมูลทั้งหมดดึงมาจาก `https://play.nightcamp.app/wiki/data/wiki_en.js` (wiki ตัวจริงยังทำหน้าย่อยไม่เสร็จ ข้อมูลดิบนี้จึงครบกว่าหน้าเว็บ) — ไม่ได้แนบมากับสกิล สคริปต์ดาวน์โหลดเองตอนใช้ครั้งแรก
อยู่ใน `data/wiki.json` (EN) + `data/th.json` (ตารางแปล EN→TH ที่เว็บใช้). ซีซันที่บันทึก: ดู `season`/`at` ในไฟล์

**ตอบเป็นไทย ใช้ชื่อไทยของเกม** (ได้จาก `nc.py th` หรือที่สคริปต์พิมพ์ต่อท้าย `/`) แล้ววงเล็บชื่ออังกฤษเมื่อจำเป็น
อย่าตอบจากความจำ — ค้นข้อมูลก่อนทุกครั้ง ตัวเลขต้องมาจากไฟล์

## เครื่องมือ

```bash
nc() { python3 -I ~/.claude/skills/nightcamp/scripts/nc.py "$@"; }   # zsh ไม่แยกคำในตัวแปร ใช้ฟังก์ชัน
nc refresh                    # ดึงข้อมูลใหม่ (ทำเมื่อ user บอกว่าเกมอัปเดต หรือ `at` เก่าเกิน ~2 สัปดาห์)
nc find <คำ>                  # ค้นชื่อ/ไอดี ไทยหรืออังกฤษ
nc show <id>                  # ทั้งเรคคอร์ด + แปลงไอดีดรอปเป็นชื่อ
nc job <job_id>               # สายอาชีพ + ทุกสกิล (ตัวเลขเลเวลสูงสุด, สกิลที่ต้องอัปก่อน)
nc drops <id|ชื่อ>            # มอนตัวไหนดรอป เรต แมพ + สูตรคราฟต์
nc map <map_id>               # มอนในแมพ: lv ธาตุ เผ่า เกราะ + สไตล์ที่เหมาะ
nc items slot=weapon wt=bow minlv=20 maxlv=40 r=epic el=fire set=1 limit=60
nc get s2.stats               # ดึงซับทรีดิบ (ใช้กับระบบที่ไม่มีคำสั่งเฉพาะ)
```

ถ้าต้องการกรองที่ซับซ้อนกว่านี้ เขียน python สั้น ๆ อ่าน `data/wiki.json` ตรง ๆ ได้เลย

## สูตรสเตตัส (ย่อจาก `s2.stats` — เช็กใหม่หลัง refresh)

- ทุกสเตตัส: แต้มเกิน cap = `min(30 + 0.55×เลเวล, 80)` ได้ผลแค่ 40% → **อย่าเทแต้มเดียวเกิน cap**
- STR: ATK ระยะประชิด 1.6/แต้ม (+0.6/เลเวล) · ทำลายเกราะ +0.4%/แต้ม
- AGI: ความเร็วโจมตี +0.5%/แต้ม (สูงสุด ×1.5) · graze 0.3% · หลบ 0.15% (สูงสุด 20%) · โดนรุมเกิน 2 ตัวหลบลด
- VIT: HP +1%/แต้ม · ลดดาเมจ 0.2%/แต้ม (สูงสุด 30%, เจาะไม่ได้) · รับฮีล +0.5% · ต้านสถานะ
- INT: MATK 1.6/แต้ม (+0.6/เลเวล) · พลังฮีล · SP
- DEX: ATK ธนู/ปืน 1.6/แต้ม · ร่ายเร็ว +0.6% (สูงสุด 50%) · แม่น 88% + 0.15%/แต้ม
- LUK: คริ 0.3%/แต้ม · ดาเมจคริ ×1.4 + 0.4%/แต้ม · โอกาสติดสถานะ +0.2%

## วิธีจัด build

1. ถามให้ครบก่อน (ถ้า user ยังไม่บอก): อาชีพ/สายที่อยากเป็น, เลเวลตอนนี้, เล่นเดี่ยวหรือปาร์ตี้, เป้า (ฟาร์มแมพ / ตีบอส / PvP), ของที่มีอยู่
2. `nc job <id>` ดูทุกสกิล → เลือกสายหลัก (`lines`) ที่ธาตุและชนิดดาเมจเข้ากัน วางลำดับอัปตาม `req`
   - แต้มสกิลมาจาก job lv (`maxJob`) — นับว่าแต้มพอกับที่เสนอ
   - สกิลหลักดูตัวคูณที่ `lvs` เทียบกับ SP/คูลดาวน์
3. สเตตัส: สเตตัสหลักของชนิดดาเมจ (STR ประชิด / DEX ระยะไกล / INT เวท) ถึง cap ก่อน แล้วเติม AGI/VIT/LUK ตามบทบาท ระบุตัวเลขต่อเลเวลที่ user ถาม
4. อาวุธ: `nc items slot=weapon wt=<ชนิดในjob.wt> minlv= maxlv=` ดู `atk`, `el`, `ab`, `wsk` + ตัวคูณ `s2.sw.W1[wt]` และชนิดดาเมจ `s2.sw.DT[wt]`
5. เทียบกับเป้า: `nc map <id>` ดูเกราะ/ธาตุ/เผ่ามอน → เลือกชนิดดาเมจที่ `s2.armour.types[arm].dt` > 1 และธาตุที่ชนะ
6. เกราะ/เซ็ต (`sets` สายที่ตรงบทบาท), รูนที่เข้ากับสกิลหลัก (`on` ตรงชนิดสกิล), Keystone (lv40+), Relic, Monster Art
7. ตอบเป็นตาราง: สกิลตามลำดับเลเวล · สเตตัสตามช่วงเลเวล · ของแนะนำ + แหล่ง (`drops`) · เหตุผลสั้น ๆ ทุกข้อ · บอกจุดที่เดาเพราะข้อมูลไม่มี (เช่นสูตรดาเมจเต็มไม่มีในไฟล์)

## ข้อควรระวัง

- เรตดรอปเป็นสัดส่วน 0–1 (0.06 = 6%) · ตัวเลขในคำอธิบายสกิล (`d`) คือค่าที่เลเวลสูงสุด
- คำอธิบายบางสกิลเขียนชนิดอาวุธไม่ตรงกับ `wt` ของอาชีพ (เช่น Ranger เขียน Bow แต่ใช้ Crossbow) → ยึด `wt`
- `data/wiki.js` บนเว็บเป็นเวอร์ชันเก่า (v1 ภาษาไทย ก.ย.) ห้ามใช้ ใช้ `wiki_en.js` อย่างเดียว (refresh ทำให้แล้ว)
- ข้อมูลเป็นซีซันทดสอบ ตัวเลขเปลี่ยนบ่อย — บอกวันที่ของข้อมูล (`at`) เวลาให้ตัวเลขสำคัญ
