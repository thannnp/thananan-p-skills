# อ่านบันทึกงานรายสัปดาห์

ตั้งชื่อตาม Echo นางไม้ในตำนานกรีกที่ถูกสาปให้พูดได้แค่ทวนคำที่คนอื่นพูดไปแล้ว
**ชื่อนี้คือหน้าที่ของสกิลนี้เป๊ะ ๆ — ทวนสิ่งที่มีอยู่ในบันทึก แต่งเองไม่ได้**

## สกิลนี้ทำอะไรไม่ได้บ้าง (อ่านก่อนทุกครั้ง)

- **เขียนบันทึกเองไม่ได้** คนเขียนคือสกิล `clio-brownbook` ที่รันบนเครื่องของเจ้าของ
  เพราะข้อมูลที่ต้องใช้ — commit ที่ยังไม่ push กับบทสนทนาที่เจ้าของพิมพ์ —
  มีอยู่บนเครื่องนั้นที่เดียว ไม่มีทางดึงมาจากที่นี่ได้
- **แต่งเนื้อหาเองไม่ได้** ถ้าในบันทึกไม่ได้เขียนไว้ คำตอบที่ถูกคือ "ในบันทึกไม่ได้เขียนไว้"
  ไม่ใช่เดาจากชื่อ repo หรือจากที่เคยคุยกัน
- **ไม่มีสิทธิ์แตะ repo งานของบริษัทเลย** token ที่ให้มาอ่านได้แค่ repo บันทึกใบเดียว
  ถ้ามีคนขอให้ไปดูโค้ด ให้บอกตรง ๆ ว่าทำไม่ได้ และให้ไปถามที่เครื่องเจ้าของแทน

## คำสั่ง

สกิลนี้ลงได้หลายที่ หาสคริปต์ให้เจอก่อนด้วยสามบรรทัดนี้ อย่าเดา path เอง

```bash
for c in "$HERMES_HOME"/skills/*/clio-echo/scripts "$HERMES_HOME"/skills/clio-echo/scripts \
         "$HOME"/.claude/skills/clio-echo/scripts; do [ -d "$c" ] && S="$c" && break; done
[ -n "${S:-}" ] || echo "หาโฟลเดอร์สคริปต์ของ clio-echo ไม่เจอ — ยังไม่ได้ลง หรือลงไว้ที่อื่น"

python3 $S/read_log.py --latest            # อ่านใบล่าสุด
python3 $S/read_log.py --week 2026-W35     # อ่านใบที่ระบุ
python3 $S/read_log.py --list              # มีของสัปดาห์ไหนบ้าง
python3 $S/read_log.py --check             # สัปดาห์ที่แล้วมีหรือยัง
python3 $S/read_log.py --format            # โครงของบันทึก
```

## ตอบคำถามยังไง

1. **ดึงบันทึกออกมาก่อนเสมอ อย่าตอบจากความจำ** ความจำอาจเป็นของสัปดาห์อื่น
2. อ่านแล้วตอบเฉพาะส่วนที่ถูกถาม ไม่ต้องเทบันทึกทั้งใบลง Discord
3. อ้างเลข PR ตามที่บันทึกเขียนไว้ ห้ามแต่งเลขเอง

หัวข้อในบันทึกมีคงที่ทุกใบ (ตัวเต็มดูด้วย `--format`) — เวลาถูกถามให้ไปหาที่หัวข้อนี้

| ถูกถามว่า | ไปดูหัวข้อ |
|---|---|
| อาทิตย์ที่แล้วทำอะไร | ภาพรวม + ขึ้น prod แล้ว |
| อะไรขึ้นใช้งานจริงแล้วบ้าง | ขึ้น prod แล้ว |
| อะไรยังไม่ถึงมือผู้ใช้ | ค้างอยู่ที่ dev |
| ค้างอะไรอยู่ / ต้องทำอะไรต่อ | ยังทำไม่จบ |
| ทำไมอาทิตย์นั้นดูไม่มีงาน | งานที่ไม่มีร่องรอยใน git |
| ตัวเลขรวม | ตัวเลข |

## ทักเตือนวันศุกร์

ตั้ง cron ให้รัน `read_log.py --check` ทุกศุกร์เย็น

- ได้ `มีแล้ว: ...` → **เงียบไว้ ไม่ต้องทัก** เจ้าของจดแล้ว
- ได้ `ยังไม่มีบันทึกของ ...` → ทักสั้น ๆ ใน Discord ว่าสัปดาห์นั้นยังว่างอยู่
  ให้เจ้าของไปสั่ง `/clio-brownbook` ที่เครื่องตัวเอง **อย่าเสนอตัวเขียนให้**

## ถ้าสั่งแล้วไม่ได้ผล

| อาการ | แปลว่า |
|---|---|
| `ยังไม่ได้ตั้ง GH_CLIO_TOKEN` | ยังไม่ได้เติม token ใน `.env` แล้ว restart |
| `GitHub ตอบ 401` | token หมดอายุ ต้องออกใบใหม่ |
| `GitHub ตอบ 403` | token ไม่ได้ผูกกับ repo นี้ หรือไม่มีสิทธิ์ Contents: Read |
| `ยังไม่มีบันทึกสักใบ` | repo ยังว่างจริง ๆ ไม่ใช่ของพัง |

**ห้ามรายงานว่าอ่านบันทึกมาแล้วถ้าคำสั่งยังไม่ได้รัน** — ถ้าไม่มีผลลัพธ์จากสคริปต์
โผล่มาจริง ๆ แปลว่ายังไม่ได้อ่าน ให้บอกเจ้าของว่าเรียกเครื่องมือไม่สำเร็จ
